# Трекер фокуса: БВИ + Олимпиады + ЕГЭ 90+

Автономное кроссплатформенное приложение для ПК и телефонов (Android / iOS).

## Запуск на телефоне

Приложение настроено как **Progressive Web App (PWA)**: его можно установить на главный экран смартфона, и оно будет работать во весь экран без адресной строки браузера и полностью офлайн.

### Способ 1. По домашнему Wi-Fi (без интернета)
1. На компьютере запусти `python run_app.py` или дважды нажми на `start.bat`.
2. В консоли отобразится строка вида:
   ```text
   [Телефон]: http://192.168.x.x:5050/index.html
   ```
3. Убедись, что телефон подключен к тому же домашнему Wi-Fi роутеру, и открой этот адрес в браузере телефона.
4. **Установка на экран телефона**:
   - **Android (Chrome)**: нажми меню (три точки) &rarr; *«Установить приложение»* (или *«Добавить на главный экран»*).
   - **iPhone (Safari)**: нажми кнопку *«Поделиться»* (квадрат со стрелкой вверх) &rarr; выбери *«На экран «Домой»»*.

После этого на телефоне появится полноценная иконка приложения.

---

### Способ 2. Бесплатный запуск через интернет (GitHub Pages)
Чтобы открывать трекер вне дома через мобильный интернет:
1. Создай бесплатный репозиторий на [GitHub](https://github.com/).
2. Загрузи файлы из папки `c:\Roblox\focus_tracker` в репозиторий.
3. В настройках репозитория (*Settings &rarr; Pages*) выбери ветку `main` и нажми *Save*.
4. Ты получишь постоянную публичную ссылку вида `https://твой-логин.github.io/focus_tracker`.
5. Открой эту ссылку на телефоне и добавь на главный экран.

## Возможности приложения

- **Почасовое расписание с таймером в реальном времени**: отслеживание текущего слота, оставшегося времени и прогресса.
- **Стратегия ЕГЭ на 90+**: чек-листы по профильной математике, русскому языку и информатике (КЕГЭ) с журналом пробников.
- **Журнал ошибок Codeforces**: разбор олимпиадных задач по пяти типовым причинам неудач.
- **Протокол гибкости**: четкие правила сокращения нагрузок при срывах расписания и усталости.
- **Zen Mode**: полноэкранный таймер концентрации со звуковым сигналом.
- **Быстрые ссылки**: Codeforces, Яндекс Контест, CSES, USACO Guide, КЕГЭ Полякова, Решу ЕГЭ.
